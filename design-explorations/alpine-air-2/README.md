# Carve Academy — Alpine Air 2.0 «Снежное поле»

Дизайн-концепт нового интерфейса. **Код продукта не изменён** — это отдельная папка со статичными HTML-макетами и рендерами.

## Что внутри

| Файл | Экран |
|---|---|
| `00-concept.html` | Концепция: принципы, цвет, типографика, компоненты |
| `01-home.html` | Главная: hero, условия склона, инструкторы, курсы |
| `02-booking.html` | Запись на занятие: дата → слот → участники → оплата |
| `03-cabinet.html` | Кабинет ученика: переключатель участников, записи, прогресс, кошелёк |
| `04-instructor.html` | Кабинет инструктора: маршрут дня, отметки посещаемости, финансы |
| `05-admin.html` | Админ: смены инструкторов, обращения, финансы дня |
| `06-mobile.html` | Мобильные экраны: главная, бронирование в bottom sheet, кабинет |

Рендеры: `png/*.png` (2× DPI).

## Направление

Не ломаем редакционную ДНК Alpine Air (серифные заголовки, тихие границы, матовое стекло).
Двигаем её в холодную «инструментальную» систему:

- **Бумажный фон** `#F6F5F1` вместо чистого белого — меньше «стерильности», больше тактильности.
- **Ледниковый акцент** `#0E5A6B` как единственная CTA-роль.
- **Один тёплый сигнал** `#C2410C` — только «требует действия» (не оплачено, ждёт отметки, дедлайн).
- **Моноширинные цифры** для времени, денег, рейтинга — их сканируют и сравнивают, а не читают.
- **Snowline-разделители** вместо рамок: группировка через воздух, карточек меньше.
- **Склон как аргумент продажи**: погода, состояние трасс и свободные слоты видны на первом экране.
- **Участник, а не аккаунт**: переключатель Participant виден всегда, у каждого свои занятия, прогресс и аватар.
- **Мобильное бронирование**: выбор даты и слота — в bottom sheet, оплата — в липкой нижней панели.

## Как перерисовать

```bash
node render.mjs   # требует playwright + chromium (уже в devDependencies)
```

Токены дизайн-системы: `tokens.css` — готовая основа для переноса в `src/index.css`.
